# Resources

This folder contains resources used by the emulator.

- `dsp_coef.bin` and `dsp_coef.bin`: Copies of Dolphin's
  [free DSP roms](https://github.com/dolphin-emu/dolphin/tree/master/docs/DSP/free_dsp_rom).
- `ipl/font_japanese.bin`: Dolphin's Apache-2.0 Shift JIS IPL font alternative,
  copied from
  [`Data/Sys/GC/font_japanese.bin`](https://github.com/dolphin-emu/dolphin/blob/707d3c7a732634ad8d522bd27e52b075f54ac4f3/Data/Sys/GC/font_japanese.bin).
  It is 259,626 bytes, has SHA-256
  `38f9f59d505bc4e2d86b0196706195f33ad72b7fe9d029cf263072cde19d044f`,
  and is mapped at IPL offset `0x1aff00`.
- `ipl/font_western.bin`: Dolphin's Apache-2.0 Windows-1252 IPL font
  alternative, copied from
  [`Data/Sys/GC/font_western.bin`](https://github.com/dolphin-emu/dolphin/blob/707d3c7a732634ad8d522bd27e52b075f54ac4f3/Data/Sys/GC/font_western.bin).
  It is 6,478 bytes, has SHA-256
  `4ad991be2b0aa305f09b90a79fc50f57833b30b008890b5ef1336cc3d9d0bae0`,
  and is mapped at IPL offset `0x1fcf00`.

The IPL font alternatives were generated by Dolphin's `gc-font-tool` from
Droid Sans. They are attributed to Google Corporation, copyright 2006–2014,
and licensed under Apache-2.0. The vendored notice and license are in
[`licenses/Dolphin-fonts-Apache-2.0.txt`](../licenses/Dolphin-fonts-Apache-2.0.txt).
The files above are pinned to Dolphin commit
[`707d3c7a732634ad8d522bd27e52b075f54ac4f3`](https://github.com/dolphin-emu/dolphin/tree/707d3c7a732634ad8d522bd27e52b075f54ac4f3).
